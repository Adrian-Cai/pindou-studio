# 小程序 0.7.1 提交信息

## 版本号

`0.7.1`

## 上传说明

优化微信登录后的账号资料流程，停止头像上传和远程头像读取，统一使用本地品牌默认头像；昵称保存后立即更新本地账号状态，提升弱网和资料刷新失败时的稳定性。

## 提审备注

- 本版本重点为微信登录、账号资料完善和个人中心体验优化。
- 登录成功后，如果账号尚未设置昵称，会自动打开资料完善弹层。
- 资料保存只更新昵称，头像始终使用小程序内置品牌头像，不依赖远程头像地址或头像上传接口。
- 账号面板支持查看当前登录状态、编辑昵称和退出登录。
- 阶段 2 的封面上传和作品云端 CRUD 已在后端完成，但尚未接入本次小程序提审流程，不作为本版本的用户可见能力。

## 建议审核路径

1. 打开小程序，进入“我的”页，点击顶部账号卡片。
2. 完成微信登录，确认登录成功后按需进入资料完善弹层。
3. 输入昵称并保存，返回“我的”页确认昵称和账号状态更新。
4. 再次打开账号面板，验证昵称编辑、登录态恢复和退出登录。
5. 观察游客态、登录态和默认品牌头像展示是否正常。
