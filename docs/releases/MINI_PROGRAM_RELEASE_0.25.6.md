# 小程序 0.25.6 提交信息

## 版本号

`0.25.6`

## 上传说明 / 项目备注

本次版本为“我的作品”操作体验优化版本：

- 将作品卡片的重命名、下载和删除操作改为卡片内联按钮，减少打开底部操作面板的额外步骤。
- 操作按钮直接绑定当前作品 ID，保留重命名、下载、删除和草稿继续编辑流程。
- 优化作品卡片操作区、重命名弹窗和按压反馈在小屏设备上的布局表现。
- 不改变作品数据、云同步、下载额度和账号流程。

## 提审备注

1. 进入“我的作品”，确认每张作品卡片都能看到重命名、下载和删除操作。
2. 点击“重命名”，确认弹窗打开、取消和保存流程正常。
3. 点击“下载”，确认能进入下载记录页面，下载额度和记录逻辑不变。
4. 点击“删除”，确认仍会弹出确认提示，取消不会删除，确认后只删除目标作品。
5. 对本地草稿确认“继续编辑”仍可用，云端作品和本地作品操作均正常。
6. 在长标题和小屏设备上检查标题、状态标签和操作按钮不重叠、不溢出。
