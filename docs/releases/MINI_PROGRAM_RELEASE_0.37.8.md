## 本次更新

- 压缩 13 张本地 PNG/JPG 图片，保持资源路径和业务流程不变。
- 包内图片、音频及 SVG 合计从 `733,788` 字节（约 `716.6 KiB`）降至 `194,523` 字节（约 `190.0 KiB`）。

- 已关闭订单卡片不再显示「重新购买」按钮。
- 文生图作品详情移除顶部介绍文案，支持复制提示词并保存原图到手机相册。
- 文生图成功结果区移除图片下方的「重新生成」和「生成拼豆图」按钮，保留原有尺寸选择、灵感生成功能及主操作入口。
- 文生图提示词强化拼豆友好约束，生成主体清晰、色块简洁、细节克制的原图。
- AI 灵感固定展示「樱花猫咪」「月亮鲸鱼」「蘑菇小屋」三条本地创意，不再请求灵感接口。
- 缩小创作页 AI 效果风格三个选项卡片，调整卡片高度、图标和文字尺寸，保持单行布局。
- 精简创作页图纸参数区，移除当前规格摘要，并调整尺寸和颜色说明文案位置。
- 修复充值页返回前台后套餐选项可能重置、复用其它套餐支付幂等键而导致下单冲突的问题；下单前校验幂等键所属套餐。
- 关于页版本号更新至 `0.37.8`。
