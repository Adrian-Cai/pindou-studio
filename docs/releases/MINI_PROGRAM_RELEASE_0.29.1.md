# 小程序 0.29.1 提交信息

## 版本号

`0.29.1`

## 建议提交信息

`release: v0.29.1 优化编辑拼豆图 AI 生成加载态预览体验`

## 微信小程序提审版本说明

优化「编辑拼豆图」页面中 AI 生成过程中的图片预览加载状态体验：新增浅紫色温和微光视觉卡片，包含调色盘与灵感星星矢量图标、清晰的进度百分比和细节优化提示胶囊；替换旧版临时加载动画，提升页面生成阶段的视觉质感与稳定性。

## 本次修改说明

1. **新增加载预览组件**：新增独立 UI 组件 `generating-preview-card`，高保真还原设计稿规范：浅紫色渐变氛围层、内联高清矢量 SVG 图标与浮动动效、进度条与百分比对齐，以及半透明磨砂白提示胶囊。
2. **编辑页深度集成**：在「编辑拼豆图」页面（`pages-sub/editor`）接入 `generating-preview-card`，在 AI 生成期间优雅展现任务进度，动态绑定 `aiProgress`。
3. **视觉调试支持**：编辑页支持 `preview=generating` 查询参数，支持在微信开发者工具或真机无真实后端网络任务时直接进行高保真 UI 验收。
4. **冗余样式精简**：清理编辑页原有 60 余行旧版临时 loading 样式与元素，组件内聚管理，提升代码可维护性。
5. **文档完善**：补充完整的 AI 生成接口字段与流转文档 `docs/backend/AI_GENERATION_API.md`。

## 影响范围

- 「编辑拼豆图」页面 AI 生成锁定等待态展示
- 新增 `miniprogram/components/generating-preview-card`

**不影响范围**：

- 普通图片快速模式转拼豆流程
- 编辑器已有手势、笔刷、橡皮擦、吸色、填充、调色盘等所有工具与画布核心渲染
- 缩放、保存草稿、下载与作品列表
- 后端 AI 生成任务生命周期与接口协议
