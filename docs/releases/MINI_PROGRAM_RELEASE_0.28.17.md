# 小程序 0.28.17 提交信息

## 版本号

`0.28.17`

## 建议提交信息

`release: v0.28.17 接入微信小程序客服`

## 提审版本说明

1. 优化意见反馈入口，接入微信小程序客服，用户可直接进入客服会话描述问题并发送截图。
2. 移除尚未接入服务端的反馈表单、截图选择和假成功提示，避免反馈内容未实际提交造成误解。
3. 同步更新客服会话、图片权限和隐私说明，服务端不新增反馈接口或数据库存储。

## 本次修改说明

1. **客服入口接入**：
   - 意见反馈页使用原生 `<button open-type="contact">` 打开已配置的小程序客服。
   - 保留现有公共导航、品牌说明和底部安全区适配。
   - 增加客服会话说明，明确用户可在会话中发送文字和截图。

2. **无效逻辑清理**：
   - 删除反馈类型、问题描述、联系方式和临时截图选择逻辑。
   - 删除“反馈内容已保存”和“反馈接口尚未配置”假成功弹窗。
   - 删除未再使用的 `FEEDBACK_CATEGORIES` 配置。

3. **文档同步**：
   - 更新后端 API、数据库设计和后端需求审计，明确不建设反馈服务端链路。
   - 更新隐私政策、第三方信息共享清单和发布检查清单。

## 影响范围

- 意见反馈页：`miniprogram/pages-sub/feedback/`
- 个人中心帮助文案：`miniprogram/config/profile.ts`
- 法律文档运行时内容：`server/src/modules/legal/legal-document-content.ts`
- 后端/API/隐私/版本文档

**不影响范围**：

- 作品生成、编辑、保存、同步和下载流程
- 服务端业务接口和数据库结构
- 用户作品、收藏、额度和支付数据
