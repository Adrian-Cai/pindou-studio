## 微信小程序提审版本说明

本次更新修复了 AI 精致生成必定失败的问题：AI 出图结果此前固定判定为“生成结果不可用”，现已按图片真实格式正确处理，可正常生成。同时优化生成等待体验：生成过程中底部展示与编辑器一致的图案控制面板（不可操作，出图后自动变为可调整），去掉等待期的原图预览、返回首页按钮与底部说明，页面更聚焦。编辑器底部控制面板已抽为公共组件，编辑器页与 AI 生成页共用同一套样式与交互，并修复了未就绪按钮未置灰的问题。标准模式生成、作品编辑、保存与下载流程保持不变。

## 本次修改说明

1. **修复 AI 精致生成必然失败**（`9554df7`）：混元图生图实际返回 JPEG，而模型临时地址缺失 `content-type` 响应头，云函数按 `|| 'image/png'` 回退把 JPEG 误标为 `.png`；服务端 `isPng()` 只认 PNG 魔数，任务恒定以 `AI_PROVIDER_OUTPUT_INVALID` 失败，小程序显示「AI 生成结果不可用，请重新生成」。现改为：云函数按下载字节的真实魔数判定 `contentType` 与文件名后缀；服务端 `HunyuanImageProvider` 接受 PNG / JPEG / WEBP，`ai-generation-service` 按实际格式命名与标注 MIME，`ai-file-storage` 移除「AI 输出必须是 PNG」限制，小程序 `AiOutputFile.contentType` 同步支持三种格式。
2. **抽出公共组件 `components/editor-control-panel`**：把编辑器底部控制面板（缩放、图案信息、工具栏、调色板、重新生成 + 保存作品）抽为主包公共组件，编辑器页与 AI 生成页共用同一套分组与样式，不再各写一份。放在主包 `components/` 是硬要求——editor 与 ai-generation 是两个分包，放任一分包都会变成跨分包引用。
3. **AI 生成页补上禁用态面板**：生成中状态渲染该面板并置灰，尺寸/颜色取本次任务设置、颗粒数按满格上限预估，调色板用占位色块保持高度稳定；生成完成跳转编辑器后同一面板变为可操作，解决等待期底部大片空白。
4. **精简生成中中间态**：生成过程中不再展示待生成的原图预览，同时隐藏「返回首页」按钮与底部合规说明，只保留顶部 AI 生成提示、生成中动画卡片与禁用态面板；`loading` 与 `failed` 态保持原样。
5. **修复禁用态按钮不生效**：面板内 `.button-primary[disabled]` 之前会被启用态配色覆盖，现在保存作品/重新生成在未就绪时明确置灰。
6. **明确分包依赖边界**：`ai-generation-flow` 上提到主包 `miniprogram/services/`，新增「分包与主包依赖规范」（`docs/frontend/MINI_PROGRAM_RULES.md` 第 7 节），禁止主包引用 `packages/` 下的模块与组件，避免启动期 `module ... is not defined` 崩溃。
7. **服务端清理任务加一次性守卫**（`5aa5040`）：`cleanupExpired()` 的 SELECT 增加 `AND (completed_at IS NULL OR status = 'succeeded')`，避免每小时把整批过期历史重新选中、重写一遍 `updated_at`，并重复调用已删除对象的 `storage.remove()`。
8. **文档与注释（无功能改动）**：为核心业务链路补齐模块职责注释，统一格式为「文件头一句话职责 + 职责边界 + 调用方 + 关键点」，导出函数补 JSDoc，行内注释只在复杂条件、阈值、状态机迁移、错误码映射、重试退避与 SQL 处添加。覆盖：`miniprogram` 的图纸模型、编辑器页与绘制服务、作品/下载/图片/支付/鉴权/作品存储、拼豆图生成（调色板选型、标准图纸生成、颜色量化、边缘检测、cleanup）、作品页；`server` 的 AI 生成链路、下载配额、微信支付、额度台账、鉴权仓储、用户资料、作品与图纸；以及 `cloudfunctions/generateImage`。任务化方案补充作品卡片三态设计与「AI 生成页改造为任务详情页（不新建页面）」方案。另有 `.gitignore` 增加 `.tmp*` / `*.tmp` 规则，避免一次性排查脚本被误提交。

## 提审验收重点

1. **AI 生成主链路**：发起精致生成后可正常出图并跳转编辑器（此前 100% 失败）。生成完成后作品列表中出现对应草稿作品。
2. **生成中底部面板**：生成过程中底部展示与编辑器一致的面板，尺寸/颜色/颗粒数按本次任务设置预填，所有操作置灰不可点；出图进入编辑器后同一面板变为可操作。
3. **生成中页面精简**：生成过程中不显示原图预览、不显示「返回首页」按钮与底部合规说明；`loading` 与失败态仍显示原有卡片与按钮。
4. **编辑器页回归**：底部面板（缩放、图案信息、工具栏、调色板、重新生成/保存作品）与改造前一致；注意「重新生成」按钮在图纸准备期会随面板一起置灰（既有行为变化）。
5. **小屏适配**：iPhone 6/7/8 上确认 AI 生成页内容可滚动，底部按钮能完整露出。
6. 标准模式生成、作品编辑、保存、下载流程与旧版本一致。
7. AI 生成失败时展示可理解的错误文案，仍可重试或切换标准模式；失败不扣次数。
8. 确认客户端包、接口响应与普通日志中不包含服务端 API Key 或模型返回的原始临时 URL。
