`0.25.14`

## 用户可见更新说明

优化首页图片上传状态展示与进度反馈，修复生成按钮宽度显示异常，提升视觉与操作体验。

## 上传说明 / 项目备注

- 修复首页“开始生成”按钮受微信小程序基础库默认样式影响导致两侧留白过大的问题，使其宽度自适应撑满内容区并与设置项卡片齐平
- 重构首页上传状态卡（upload-status-card），支持上传进度实时百分比与进度条展示，并优化检测中、检测未通过及失败状态的视觉与操作反馈
- 更新品牌头像高清资源

## 提审重点

1. 打开小程序首页，检查“开始生成”主按钮宽度与上方的尺寸/颜色数量配置卡片左右边缘完美对齐，无多余留白
2. 点击“上传图片”选择图片，确认上传过程中展示实时上传进度百分比与进度条
3. 上传完成后确认图片正常通过内容安全检测并进入就绪状态，点击“开始生成”正常流转至生成/编辑流程
4. 验证图片上传异常或检测未通过时，错误提示及“重新选择”按钮操作正常
