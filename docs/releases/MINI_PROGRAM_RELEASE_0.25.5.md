# 小程序 0.25.5 提交信息

## 版本号

`0.25.5`

## 上传说明 / 项目备注

本次版本为隐私合规与品牌信息更新版本：

- **法律文档正式化**：新增并发布版本化的《小露拼豆隐私政策》《个人信息收集清单》和《第三方信息共享清单》，三份文档统一使用 2026-09-07 版本。
- **隐私入口可体验**：登录弹窗中的《隐私政策》可直接点击，未登录状态也可以进入并查看隐私文档；隐私设置页保留三份文档入口。
- **云同步行为收敛**：登录或恢复登录不再自动迁移本地作品；只有用户在隐私设置中明确开启云同步并确认后，才会迁移已有本地作品。
- **品牌信息统一**：小程序首页、登录弹窗、关于页面和支付订单描述统一使用“小露拼豆”。

## 提审备注

1. 在“我的”页面打开登录弹窗，点击“《隐私政策》”，确认无需登录即可正常进入并展示文档内容。
2. 进入“我的” → “隐私设置”，依次打开隐私政策、个人信息收集清单和第三方信息共享清单，确认标题、版本和正文正常展示。
3. 确认首次登录或恢复登录不会自动上传本地作品；在隐私设置中开启云同步时，确认会先弹出迁移确认，并仅在确认后执行迁移。
4. 检查首页、登录弹窗、关于我们和个人中心底部，确认品牌名称与版本显示为“小露拼豆”和 `0.25.5`。
5. 回归图片选择、标准生成、作品保存、编辑、下载、收藏和注销账号主流程。
