# 小程序 0.25.9 提交信息

## 版本号

`0.25.9`

## 用户可见更新说明

优化作品结果页与我的作品列表中的卡片视觉与操作布局，提升标题可读性与操作便捷度。

## 上传说明 / 项目备注

- 优化作品结果页标题编辑按钮布局：标题与 Pencil 编辑按钮并入同一个 flex 容器，编辑按钮紧贴标题右侧（间距约 6px），长标题自适应省略且保证编辑按钮不被压缩，右侧保持与收藏按钮的安全间距
- 优化“我的作品”卡片布局与结构：作品信息区域聚合在左侧，状态标签右对齐，卡片底部重命名、下载、删除操作两端对齐分布，提升垂直空间利用率与不同机型下的对齐体验
- 本次为页面 UI 视觉与交互微调，不调整底层业务逻辑、网络接口、登录授权与数据存储
