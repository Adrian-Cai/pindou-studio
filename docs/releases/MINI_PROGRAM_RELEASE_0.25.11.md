## 用户可见更新说明

优化“我的收藏”作品卡片操作体验，查看作品、下载和取消收藏现在可直接操作，减少多余菜单层级。

## 上传说明 / 项目备注

- 移除收藏卡片的已收藏入口、独立查看按钮、三点菜单及底部操作面板
- 在作品信息下方直接展示“查看作品 / 下载 / 取消收藏”轻量操作栏，并与“我的作品”操作区保持一致
- 保留原有查看、下载和取消收藏业务逻辑；取消收藏后立即刷新列表、收藏总数和最近新增统计
- 保持缩略图尺寸、标题字号、卡片圆角、阴影以及页面其他区域不变

## 提审重点

1. 进入“我的收藏”页，确认每张卡片直接显示查看作品、下载、取消收藏三个操作
2. 确认页面不存在已收藏按钮、独立查看按钮、三点菜单和底部作品操作面板
3. 在小屏设备和长标题场景下，确认标题单行省略，三个操作保持一行且不遮挡图片、不超出卡片
4. 分别点击查看作品和下载，确认沿用原有页面跳转逻辑
5. 点击取消收藏，确认作品立即从列表消失，收藏总数和最近新增统计同步更新
