# 小程序 0.30.34 提审说明

## 版本号

`0.30.34`

## 建议提交信息

`release: v0.30.34 修复 AI 生图结果、预览与云端保存`

## 微信小程序提审版本说明

本次更新修复 AI 生图切换模型后的结果处理问题，优化生成结果预览，并提升作品保存可靠性。ToAPIs 已完成的图片可正常下载并进入拼豆图预览；登录用户保存作品时优先同步云端，网络异常时先保留本机并在恢复网络后继续同步。标准模式生成、作品编辑、支付与下载流程保持不变。

## 本次修改说明

1. **修复 ToAPIs 图片结果处理**：兼容 `result.data[0].url`、`result.url` 和顶层 `url` 返回结构；服务端输出域名白名单支持 `files.toapis.cn` 与 `files.toapis.com`，避免图片地址被误判为不受信任。
2. **增强 AI 失败诊断**：服务端日志区分提交、轮询和下载阶段，并保留供应商错误码、HTTP 状态和输出域名；图片格式校验失败时记录格式、字节数和文件签名，便于定位真实原因。
3. **优化生成结果预览**：AI 生成页直接绘制拼豆图画布，预览不再依赖临时源图片地址；编辑器和生成页复用同一套拼豆图渲染逻辑。
4. **修复云端保存与离线兜底**：登录用户保存结果时同步云端；网络异常时保留本机作品并排队同步，避免保存成功但云端作品缺失。

## 影响范围

- AI 生成服务端 ToAPIs 任务轮询、输出下载与错误日志
- AI 生成页结果预览与作品保存
- 编辑器拼豆图画布渲染逻辑复用
- 小程序版本号与提审说明

**不影响范围：**

- 标准模式拼豆图生成算法
- 登录、支付、额度与下载接口协议
- 已有作品编辑流程和数据库结构

## 发布前置条件

1. 服务端生产环境配置：

   ```text
   TOAPIS_IMAGE_OUTPUT_HOSTS=files.toapis.cn,files.toapis.com
   ```

2. 部署服务端新镜像，并确认 `/health` 返回 200、容器状态为 healthy。
3. 通过真实测试账号完成一次 ToAPIs AI 生图，确认任务状态为 `succeeded`，并能进入拼豆图编辑器。
4. 微信开发者工具清除缓存后重新编译，确认小程序版本为 `0.30.34`。
5. 验证登录保存、网络异常保存和恢复网络后的同步行为，再提交审核。

## 提审验收重点

1. ToAPIs 生图成功后能正常下载图片、展示拼豆图预览并进入编辑器。
2. AI 结果预览绘制失败时显示明确提示，不出现空白结果卡片。
3. 登录状态保存作品后，作品列表能读取云端作品。
4. 保存期间断网时，本机作品不丢失，恢复网络后可以继续同步。
5. 标准模式生成、编辑、保存、下载和支付流程回归正常。
