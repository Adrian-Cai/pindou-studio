# 小程序 0.25.0 提交信息

## 版本号

`0.25.0`

## 上传说明 / 项目备注

本次版本聚焦标准生成质量、下载额度口径和界面主题一致性：

- **标准生成质量回归**：补齐 OKLab 感知匹配专项测试，覆盖 Green/Blue 参考值、严格 tie、RGB/OKLab 分歧、Alpha 31/32 和 `colorLimit`。
- **Phase 5 保守清理**：对 MARD 映射后的孤立近色斑点执行局部清理，只替换高一致性且感知距离接近的邻域，不填充透明格、不引入新色，也不修改输入矩阵。
- **下载额度口径统一**：标准模式每日免费成功保存 9 个文件，小程序本地默认值、个人中心、下载记录和额度说明与服务端保持一致；AI 额度仍由服务端独立返回。
- **暗色模式首轮适配**：首页、结果页、编辑器、共享弹层及主要二级页面接入系统主题语义 token，并统一卡片、次级按钮、Ghost/Glass 样式和点击反馈。
- **隐私与账号入口保持可用**：隐私设置、隐私文档和账号管理入口继续保留，未改变云同步与注销的服务端安全边界。

## 提审备注

1. 进入“我的” → “关于我们”，确认版本显示为 `0.25.0`；进入“我的” → “下载记录”，确认每日额度文案为 9 次。
2. 在系统浅色主题和深色主题下分别检查首页、结果页、编辑器、下载弹层、个人中心和主要二级页面，确认文字、卡片、按钮和分隔线可读。
3. 使用同一张图片分别生成标准图案，确认结果仍可编辑、保存、生成成品图、材料清单、施工图和色板参考。
4. 验证一个高对比主体和一个包含细小近色区域的图片，确认 Phase 5 清理不会填充透明格、不会新增色号，且最终颜色数不超过 `colorLimit`。
5. 登录后确认服务端额度展示优先于本地缓存；下载成功后扣减 1 次，取消、失败或权限拒绝不扣次数。
6. 进入隐私设置、隐私文档和账号注销流程，确认已有登录、云同步、失败回滚和注销提示不受主题调整影响。
