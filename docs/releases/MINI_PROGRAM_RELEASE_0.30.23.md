## 版本号

`0.30.23`

## 版本概述

本版本优化 AI 生成流程：生成中、生成失败、生成成功统一在同一个「AI 生成」页面内原地切换，不再跳转或单独维护失败页面。

## 本次修改说明

1. **收敛为单页面状态流**：失败状态在当前页面直接切换为「AI 生成失败」卡片，提供「重新生成 / 返回首页」操作。
2. **保留页面框架信息**：保留顶部导航、`100%` 缩放、尺寸 `64×64`、颜色 `32色`、共 `4096` 颗，以及底部导航栏。
3. **完善生成中状态**：保留紫色加载卡片、生成进度与提示文案，卡片内提供「取消生成 / 返回首页」横向按钮。
4. **完善生成成功状态**：当前页面展示生成结果，并启用缩放、工具、色板与「重新生成 / 保存作品」操作。
5. **编辑区状态明确**：生成中与生成失败时，编辑工具栏和颜色选择保持显示但处于禁用态；生成成功后恢复可用。

## 提审说明

AI 生成页面的状态切换方式优化，不改变现有生成任务流程与底部导航结构。请重点验收：

- 生成中：加载卡片、约 `60%` 进度、取消生成与返回首页按钮是否正常显示。
- 生成失败：当前页面原地切换失败卡片，不出现独立失败页、图片预览或提交时间信息。
- 生成成功：当前页面展示结果，编辑工具与颜色选择恢复可用，可重新生成或保存作品。
- 三种状态下：`100%`、`尺寸：64×64`、`颜色：32色`、`共 4096 颗`及底部导航均保留。
