## 微信审核版本说明

优化首页「生成方式」选择体验，并改造图片安全检测卡片：标准模式使用浅蓝色卡片，AI 模式使用浅紫色卡片，选中状态以描边和勾选清楚区分；简化模式图标，并缩小问号说明入口的触发范围，避免点击旁边空白处误展开说明。图片检测卡片改为纵向大图，检测提示收纳在下方单行状态栏并依次轮播；右上角可移除图片并返回上传态。本次仅调整小程序首页视觉和图片移除交互，不改变模式选择逻辑、图片检测接口、图片生成流程或数据收集行为。

## 本次更新

### 首页生成方式

- 标准模式始终保留浅蓝色背景，使用简洁的 3×3 拼豆图标。
- AI 模式始终保留浅紫色背景，使用透明底的星芒与豆粒图标。
- 选中状态通过同色描边和勾选标记表达，不让未选中卡片回到纯白。
- 只有点击问号图标附近的控件区域才展开模式说明，减少右侧空白区域误触。

### 图片安全检测卡片

- 将左侧缩略图改为纵向大图，右上角提供移除入口。
- 检测中的提示收纳在图片下方的单行状态栏并循环轮播；通过后显示简短结果。
- 移除图片后清空检测结果并返回上传态；丢弃在途校验的迟到结果。
- 保留上传进度、内容驳回和网络失败状态。
