## 本次更新

- 创作页新增「上传图片 / 描述想法」Tab，并与首页入口状态对应。
- 文字灵感创作支持服务端获取 AI 灵感、清空描述、选择生成尺寸及查看额度。
- 文生图任务保存所选尺寸；失败重试和任务恢复沿用原尺寸，避免重复提交。
- 生成成功后复用现有拼豆草稿、编辑器和作品结果流程。
- AI 生成页移除“当前生成结果由人工智能生成”提示条和“AI 精致生成”卡片标题。
