# 小程序 0.24.0 提交信息

## 版本号

`0.24.0`

## 上传说明 / 项目备注

本次版本完成隐私偏好与账号管理闭环：

- **隐私偏好云端同步**：本地保存、云同步、服务通知、个性化推荐四项偏好支持服务端读取和更新；本地保存与云同步保持互斥。
- **云同步确认机制**：开启云同步前二次确认是否上传当前设备上的本地作品；同步失败时保留本地作品，不静默丢失数据。
- **隐私文档页面**：新增隐私政策、个人信息收集清单和第三方信息共享清单页面，支持加载中、空内容、失败重试和未登录访问。
- **账号注销**：新增注销确认、处理中状态、服务端注销、会话退出和失败提示流程。
- **离线行为明确**：无网络时仅保存本机状态，并明确提示本次修改尚未同步；恢复联网后以服务端偏好为准。

## 提审备注

1. 隐私设置页入口：进入“我的” → “设置” → “隐私设置”。
2. 未登录状态可以查看三份隐私文档；开启云同步和注销账号必须先登录并保持网络可用。
3. 开启云同步时，确认弹窗会说明是否上传当前设备的本地作品；关闭云同步不会删除已经存在的云端作品。
4. 注销账号会清理账号展示信息、撤销会话、停用云端作品并标记文件资产；财务订单和额度流水保留用于审计。
5. 当前法律文档为版本化服务端内容，正式发布前需替换为经过审核的正式法律文本。

## 建议审核路径

1. 未登录进入隐私设置，打开三份文档，确认内容加载、返回和失败重试正常。
2. 登录后分别切换四项偏好，确认服务端保存成功，重新进入页面后状态保持一致。
3. 关闭网络后切换偏好，确认提示“本次修改尚未同步”，页面不会误显示云端已更新。
4. 开启云同步，确认二次弹窗出现；选择取消时开关保持关闭，选择确认后本地作品逐项同步。
5. 模拟同步接口失败，确认开关回滚且本地作品仍可查看。
6. 进入注销账号，确认二次确认、处理中状态、成功退出和失败提示均正常。
