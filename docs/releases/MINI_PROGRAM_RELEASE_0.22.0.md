# 小程序 0.22.0 提交信息

## 版本号

`0.22.0`

## 上传说明 / 项目备注

本次版本围绕“更精准的可施工图案”与“云端额度与下载闭环”展开：

- **图案生成质量升级**：最终颜色匹配升级为 OKLab 感知距离，并按固定版本的 MARD 真实施工色卡输出真实色号与屏幕参考色（当前默认 221 个不透明经典色号，完整 291 色源数据保留）；Median Cut 候选色收敛后按加权贪心选色，平均实际输出色数提升，生成结果更贴近实际可购买的拼豆色号
- **色板参考纳入云端下载闭环**：登录用户保存色板参考后按标准下载额度扣减并写入云端下载历史，下载记录页与“我的”页面和云端一致，本地色板记录不再重复展示
- **云端额度分级**：标准下载免费额度调整为每日 9 次，新增独立的每日 3 次 `ai_generation` 额度；套餐、订单与流水按 `quota_kind` 记账，个人页与结果页正确展示额度，并在下载成功后即时刷新
- **支付/充值**：套餐价格与额度完全由服务端提供，接入微信支付 v3 下单与回调；支付成功页额度改为服务端刷新结果，客户端参数不能直接增加额度
- **收藏卡片布局优化**：改为单列全宽，左侧预览、右侧信息与底部操作，长标题支持省略
- **生产后端域名**：试运行与正式环境统一配置为 `https://api.pindou.wiac.xyz`

注：本版本服务端已具备千问图像 3.0 异步生成、任务状态机与独立 `ai_generation` 额度能力；但小程序“Ai 模式”的调用接线与真实生产配置仍需按上线验收文档完成，本次提交不包含可用的 AI 生成功能

## 提审备注

1. **图案生成结果更真实**：生成结果的 `color` 与 `colorCode` 现在直接使用真实 MARD 色卡的屏幕参考色与色号；HEX 仅表示屏幕近似色，实物仍可能受批次、材质和光线影响
2. **云端下载闭环**：登录用户先查询云端额度，保存色板参考或真正导出图片后将按标准下载额度扣减并写入云端下载历史；服务端失败时保留本地缓存兜底，并不重复扣减
3. **额度分级与刷新**：标准下载与 AI 生成额度独立记账；“我的”页面显示云端最新下载次数与剩余额度，下载成功后即时刷新
4. **支付能力**：套餐价格、额度和会员类型完全由服务端读取，接入微信支付下单与验签回调；客户端无法通过改参数增加额度
5. **数据安全**：登录、作品上传、下载上报均使用服务端鉴权与幂等键，失败或弱网时保留本地记录，不丢失用户数据
6. **范围说明**：本次提交不改变图片生成、编辑、作品保存与本地下载到相册的既有交互；`Ai 模式` 在本次提交中仍为产品入口与 UI，未接入可用生成能力

## 建议审核路径

1. 未登录时从首页上传一张图片，进入编辑页保存，确认生成的图案使用真实色号且“材料清单/施工图/色板参考”可正常生成
2. 登录后进入“我的”，确认显示云端标准下载额度（每日 9 次）与剩余额度；在结果页成功保存一张图片后返回“我的”，确认下载次数增加且剩余额度立即刷新
3. 在编辑页保存色板参考，进入“我的作品/下载记录”，确认出现云端色板参考下载记录，且本地色板记录不重复
4. 进入“充值”页，确认套餐价格与额度由服务端返回；完成支付后确认额度份额到账
5. 进入“我的收藏”，确认卡片为单列全宽布局，长标题显示为省略号
6. 在弱网或后端不可用时重复上述登录/保存/下载流程，确认失败不会删除本地数据，网络恢复后可继续同步
