## 微信审核版本说明

首页升级为灵感工坊，用户可以从图片或想法开始创作。图片创作保留标准拼豆转换，并新增 Q 版、卡通插画和极简插画 AI 风格；文字创作可生成参考图并继续制作拼豆图。使用 AI 图片或文字创作前需登录。

## 本次更新

- 首页更新品牌横幅、创作入口和创作流程示意，支持从图片或想法开始。
- 图片创作新增 Q 版、卡通插画、极简插画三种 AI 风格，默认使用 Q 版。
- 文字灵感创作经内容安全检查后生成参考图，可继续进入拼豆制作流程。
- AI 图片创作和文字灵感创作要求先登录；标准模式的图片转拼豆流程保持不变。
