# 小程序 0.28.2 提交信息

## 版本号

`0.28.2`

## 用户可见更新说明

修复结果页点击收藏时提示服务内部错误的问题，提升收藏操作的稳定性。

## 提审说明

本版本主要修复登录用户在结果页点击收藏或取消收藏时，因服务端数据库参数类型解析异常导致操作失败的问题。收藏状态、收藏列表和个人中心统计的既有业务逻辑保持不变。

## 主要更新

- 修复结果页点击“收藏作品”时接口返回 500 的问题
- 修复取消收藏及重复收藏场景的服务端参数解析异常
- 保持收藏状态、收藏时间和收藏列表排序规则不变
- 关于页版本号更新为 `0.28.2`
