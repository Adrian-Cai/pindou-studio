# 小程序 0.25.3 提交信息

## 版本号

`0.25.3`

## 上传说明 / 项目备注

本次版本为作品名称内容安全与小程序包体优化版本：

- 作品创建和名称修改统一经过服务端文本安全校验
- 对 `色情`、`贩卖毒品`、色情/成人视频、赌博/博彩、制作爆炸物、诈骗转账等高置信度违规短语增加本地兜底拦截，避免第三方审核漏判
- 内容安全服务缺失、审核失败或命中风险时采用失败关闭策略，不写入作品
- 移除主包中遗留的微信 Canvas 基线测试入口，测试代码和 fixture 不再随产品入口进入主包
- 将法律文档服务迁移至 `pages-sub` 分包，避免主包携带分包专用 JS 文件
- 优化“我的作品”卡片标题、状态标签、更多操作和改名弹窗按钮布局，保持小屏显示稳定
- 统一项目标识为 `pindou_studio`，同步更新 npm 和微信开发者工具配置
- 不改变作品生成、编辑、下载和正常命名流程；页面无新增布局模块

## 提审备注

1. 进入结果页，编辑作品名称并保存一个正常名称，确认保存成功且作品列表同步更新
2. 在测试环境分别输入 `色情`、`贩卖毒品` 等高风险标题，确认提示“你发布的内容含违规信息，请修改后重试”，且作品列表中不会出现新名称
3. 验证云端作品改名和本地作品改名，两条路径均能拦截风险标题
4. 暂停或模拟内容安全服务不可用，确认标题不会静默保存；恢复服务后正常名称可继续保存
5. 回归图片生成、作品保存、作品列表、下载和收藏流程

- `git diff --check` 通过

- 微信开发者工具和真机视觉验收仍需在上传前完成
