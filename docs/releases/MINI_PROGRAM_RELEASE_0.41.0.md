# 小程序 0.41.0 接入说明

## 版本

- 小程序：`0.41.0`
- 服务端：`0.23.0`
- 数据库：新增 `server/sql/024_qq_account_link.sql`

## 本次更新

- 增加 QQ 登录；首次登录可使用 QQ 建立独立账号，也可通过微信账号签发的一次性绑定码绑定现有账号。绑定后共享作品和额度，不自动合并其他账号。
- 当前会话记录登录平台；当前用户接口返回已绑定平台。旧客户端登录请求默认使用微信，历史会话默认按微信平台处理。
- QQ 端可查看订单和使用已有额度，但不显示购买入口；服务端拒绝 QQ 会话创建订单、继续支付或取消订单。
- 注销账号时清理 QQ 身份及未使用的绑定码。隐私政策、个人信息收集清单和第三方共享清单更新至 `2026-10-16`。
