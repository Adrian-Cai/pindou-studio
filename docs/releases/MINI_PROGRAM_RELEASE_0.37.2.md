## 本次更新

- 图片尺寸改为一行四项，展示比例和分辨率，支持 `1:1`、`16:9`、`9:16` 画幅。
- 修复模型返回格式与图片文件扩展名不一致的问题；图片加载失败时显示提示并可重新读取，不重复扣除额度。
- 调整生成页信息与滚动布局，保持主要生成按钮可见。
- 关于页版本号更新至 `0.37.2`。
