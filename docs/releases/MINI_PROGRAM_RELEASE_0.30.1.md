# 小程序 0.30.1 提审说明

## 版本号

`0.30.1`

## 建议提交信息

`perf: v0.30.1 优化小程序包体与分包加载体验`

## 微信小程序提审版本说明

接入 AI 生成次数的微信支付与服务端到账确认，补充支付结果展示和异常恢复；同时优化「编辑拼豆图」首次进入时的图纸准备体验、生产包体积和分包加载时机，提升关键操作的可识别性。

## 本次修改说明

1. **接入微信支付流程**：充值页和“我的”页从服务端读取 AI 生成次数套餐，创建订单后调用 `wx.requestPayment`，不接受客户端提交的价格或额度。
2. **以服务端结果为准**：支付结果页根据订单状态刷新 AI 额度；服务端通过微信支付回调验签、订单校验和幂等发放，取消、失败、重复通知不会重复增加额度。
3. **补充支付联调能力**：增加仅限从未购买过 AI 次数账号的一次性新人测试套餐 `ai_generation_new_user_5`（¥0.10 / 5 次），仅用于联调，正式面向用户发布前必须停用。
4. **调整正式套餐**：保留 AI 生成 30 次和 80 次套餐，下架 150 次套餐，并同步更新价格规划、付费服务协议、第三方信息共享说明和支付接入文档。
5. **优化编辑器首帧**：Canvas 首次绘制完成前展示“正在准备图纸”状态，完成后平滑揭示图纸；准备期间禁用画布编辑、缩放、调色和保存，避免白色空画布造成误解。
6. **优化个人中心图标**：为“我的收藏”“下载记录”“设置”入口补充柔和的粉色、蓝色和紫色线性图标，与“我的作品”的绿色图标保持同一 Iconsax 视觉风格，增强入口区分度。
7. **优化生产包体**：排除 `tests` 和 `test-assets` 上传，清理 28 个确认未引用的 SVG 图标，并压缩默认头像与首页 4 张示例图，减少无效资源和上传体积。
8. **优化分包加载**：移除进入“我的”页面时对整个 `pages-sub` 分包的预加载，改为进入具体分包页面时按需加载，避免提前下载编辑器、结果页和支付等暂时用不到的页面。
9. **同步版本信息**：根目录版本、关于页版本和变更记录统一为 `0.30.1`。

## 影响范围

- 小程序充值页、个人中心、支付结果页和编辑拼豆图页面
- 个人中心“我的作品 / 我的收藏 / 下载记录 / 设置”入口图标
- 小程序生产包资源、测试资源上传规则和分包加载策略
- 服务端支付创建、微信支付回调、AI 额度发放和订单状态
- 数据库迁移、支付配置、付费服务协议和上线验收文档

**不影响范围**：

- 标准模式拼豆图生成算法和图纸数据格式
- AI 生成成功后的编辑、保存和结果查看主流程
- 下载次数扣减与文件保存成功后计次规则

## 发布前置条件

1. 数据库迁移 `011` 和 `012` 已由用户使用 owner 在 DBeaver 手工执行；上线前复核 API 当前连接的数据库，支付联调完成后将 `ai_generation_new_user_5` 的 `enabled` 更新为 `FALSE`，再面向普通用户提交审核。
2. 完成微信支付商户号与小程序 AppID 绑定，配置商户证书、API v3 密钥、平台公钥和 HTTPS 回调地址。
3. 将 API HTTPS 域名加入小程序 `request` 合法域名；已有账号如未保存支付所需身份信息，需要重新登录一次。
4. 正式环境确认支付配置完整；配置缺失时应保持支付关闭，不得向用户发起真实扣款。

## 提审验收重点

1. 清除微信开发者工具缓存并重新编译，确认“关于我们”显示 `Version 0.30.1`。
2. 进入“我的”页面，确认四个功能入口图标均有颜色、线性风格统一，文字和跳转行为正常。
3. 重新运行代码依赖分析，确认 `tests`、`test-assets` 和已清理 SVG 不再进入生产上传包。
4. 进入“我的”页面后观察分包加载记录，确认不会提前下载整个 `pages-sub`；进入编辑器时确认加载状态正常显示。
5. 标准模式点击“开始生成”后进入编辑页，确认 Canvas 未绘制完成前显示“正在准备图纸”，图纸完成后正常淡入，期间无法误触编辑和保存。
6. 使用从未购买过 AI 次数的测试账号完成新人福利支付联调；确认金额为 ¥0.10、到账 5 次，并确认同一账号第二次购买会被服务端拒绝。
7. 使用正式套餐完成一次支付，确认支付结果页只依据服务端订单和 `/api/quota/me` 展示到账结果。
8. 分别验证取消支付、支付失败、支付结果待确认、错误签名、错金额和重复回调：不得错误发放或重复发放 AI 次数。
9. 验证 AI 生成、编辑保存、作品结果、下载次数和登录恢复等既有流程未受影响。
