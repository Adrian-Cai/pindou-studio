# 小程序 0.28.15 提交信息

## 版本号

`0.28.15`

## 建议提交信息

`release: v0.28.15 统一小程序第三批图标视觉`

## 用户可见更新说明

统一首页、作品、我的及收藏相关页面的图标风格，提升界面一致性和操作识别度。

## 提审说明

本版本主要完成小程序第三批高频图标统一：底部主导航、个人中心入口、作品统计、作品卡片操作、收藏卡片操作和结果页收藏按钮统一使用 Iconsax 线性 SVG 图标。保留原有页面布局、文案、跳转、收藏、下载、重命名和删除流程，不调整业务接口和数据结构。

## 主要更新

- 底部 Tab 统一为 `home-2`、`gallery`、`profile-circle`，普通态与激活态保持一致的线性描边语言
- “我的”页面作品、收藏、下载、设置入口统一为 gallery、heart、document-download、setting-2
- “我的作品”页面统计图标统一为 gallery、clock、document-text，卡片操作统一为 edit-2、download、trash
- “我的收藏”页面的搜索、排序、统计、查看、下载、取消收藏和空状态图标统一
- 结果页作品摘要编辑与收藏按钮移除 Unicode 图标，改用 SVG 状态图标
- 所有本次涉及的装饰性图标补充无障碍隐藏标记；不改变触控区域和已有业务行为
