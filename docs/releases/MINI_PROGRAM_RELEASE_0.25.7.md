# 小程序 0.25.7 提交信息

## 版本号

`0.25.7`

## 用户可见更新说明

优化登录与图片生成流程，新增用户协议和安全检测状态提示，提升作品编辑、收藏和下载体验。

## 上传说明 / 项目备注

本次版本主要更新：

- **登录体验升级**：重构“我的”页登录半屏弹窗，增加用户协议与隐私政策入口；用户勾选并同意协议后才能发起微信登录
- **协议内容补齐**：新增《小露拼豆用户协议》，继续支持未登录查看法律文档
- **图片安全状态可见**：图片选择后展示内容安全检测状态、步骤和较长等待提示；未通过检测时禁止继续生成
- **标准生成优化**：Standard Pattern Engine V2 新增基于 luminance 与 Sobel 梯度的 Edge Protection，保护高对比结构附近的关键颜色
- **结果页交互优化**：收藏按钮增加处理中状态、无障碍状态和成功/失败反馈，标题编辑与操作布局同步优化
- **组件与资源整理**：下载相关组件归属 `pages-sub` 分包，新增上传状态卡、登录插图资源和相关图标，减少主包无关代码

## 提审重点

1. 未登录进入“我的”页，打开登录弹窗，确认用户协议和隐私政策均可点击查看
2. 未勾选协议时点击微信登录，确认会提示并阻止登录；勾选后可正常进入既有登录流程
3. 首页选择图片，确认安全检测状态、步骤提示和异常状态可正常展示
4. 图片未通过内容安全检测时，确认“开始生成”不可继续
5. 完成标准模式生成，确认 Edge Protection 不改变 Pattern Schema、色板结构和结果页主要流程
6. 在结果页测试收藏、取消收藏、标题编辑、下载和返回流程
7. 清除微信开发者工具缓存后重新编译，确认主包不再包含分包专用组件和无关文件
