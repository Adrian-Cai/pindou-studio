# 小程序 0.28.18 提交信息

## 版本号

`0.28.18`

## 建议提交信息

`release: v0.28.18 修复付费服务协议访问`

## 微信小程序提审版本说明

完善 AI 生成次数购买说明，新增可查看的《付费服务协议》，明确套餐、次数到账、退款及异常处理规则；当前支付能力仍未正式接入，不会产生真实扣款。

## 本次修改说明

1. **协议接口修复**：服务端正式注册 `paid-service` 法律文档 key，修复线上接口返回 404 的问题。
2. **充值页入口**：充值页“支付即表示同意《付费服务协议》”支持点击，整行提供触控反馈并复用现有法律文档阅读页。
3. **协议入口补充**：关于页新增“付费服务协议”入口，用户无需进入充值流程也可以查看。
4. **真实状态保持**：保留“支付能力接入前不会产生任何费用”提示，不接入或伪造真实支付流程。

## 影响范围

- 充值页协议入口与法律文档阅读页
- 关于页协议入口
- 服务端法律文档读取接口
- 版本与发布文档

**不影响范围**：

- 图片生成、编辑、保存、同步和下载流程
- AI 生成任务处理逻辑
- 订单、额度和微信支付回调逻辑
- 数据库结构和已有用户数据

## 提审重点

1. 清除微信开发者工具缓存并重新编译，进入“我的 → 购买 AI 生成次数”。
2. 点击“支付即表示同意《付费服务协议》”整行，确认能打开协议正文并显示版本、生效日期。
3. 进入“关于我们”，确认“付费服务协议”入口可正常打开。
4. 检查协议长文本滚动、返回按钮、顶部导航和底部安全区无遮挡。
5. 确认充值页仍显示“支付能力接入前不会产生任何费用”，点击“立即支付”仍不会发起真实扣款。
6. 在小屏 iPhone、Android 和深色模式下检查协议入口与正文可读性。
