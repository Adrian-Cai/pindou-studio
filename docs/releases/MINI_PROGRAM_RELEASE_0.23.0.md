# 小程序 0.23.0 提交信息

## 版本号

`0.23.0`

## 上传说明 / 项目备注

本次版本重点升级“内容合规与安全检测体系”，确保平台完全符合微信小程序内容安全规范：

- **接入微信内容安全检测**：
  - 图片上传全面接入微信内容安全检测（`mediaCheckAsync`），前端上传前自动对超限/非标准格式图片进行标准化转换，服务端同步快速拦截高危图片并记录异步追溯 Trace，原始审核图片仅临时存储并在审核完成或过期后自动清理。
  - 作品新建保存、作品重命名、本地作品自动同步均在服务端与客户端执行文本安全检测（`msg_sec_check`），拦截低俗、违规等不良文本。
- **无感会话机制**：首次触发上传图片或作品保存/改名等内容操作时，自动建立微信登录会话，确保未手动登录用户也能顺畅完成安全校验并继续创作。
- **隐私与信息合规**：在“隐私政策 - 第三方信息共享清单”中补充说明内容安全检测的数据流转与临时图片生命周期，保障用户知情权。
- **项目与文档结构梳理**：全面整理项目各模块技术文档，分层归档至 `docs/architecture`、`docs/backend`、`docs/development`、`docs/frontend`、`docs/product`、`docs/releases` 等标准目录。

## 提审备注

1. **内容安全全链路合规**：已接入微信官方文本（`msg_sec_check`）与图片（`mediaCheckAsync`）内容安全检测接口。用户上传的制作参考图、生成的作品封面以及用户自定义的作品名称均经过安全检测，违规内容将直接拦截并给出合规指引。
2. **临时文件安全规范**：用于媒体审核的临时图片在服务端具有严格的过期与清理机制，审核完成或过期后自动销毁，不作长期保留。
3. **隐私清单更新**：在小程序内“设置 - 隐私政策 - 第三方信息共享清单”中如实公示了微信内容安全服务的数据处理说明。
4. **核心业务与离线体验保持稳定**：拼豆图案转换、经典 MARD 221 色匹配、四项下载（成品图、材料清单、施工图、色板参考）均保持既有高标准体验；网络不佳或服务端异常时本地草稿与数据完整保留。

## 建议审核路径

1. 首页上传一张普通手工/日常图片，确认界面提示“正在安全检测”并顺利进入图案生成与编辑页面。
2. 在结果页点击作品标题进行重命名，输入正常标题确认保存成功；若包含违规词汇，将提示“你发布的内容含违规信息，请修改后重试”。
3. 在“我的作品”列表中对草稿或作品执行重命名，验证文本安全检测机制。
4. 进入“我的”页面，点击“设置”或“隐私政策”中的“第三方信息共享清单”，确认查看内容安全数据说明。
5. 在作品结果页查看“成品图”、“材料清单”、“施工图”及“色板参考”，测试完整生成与导出流程。
