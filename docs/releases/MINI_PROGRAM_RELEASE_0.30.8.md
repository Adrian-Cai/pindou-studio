## 微信小程序提审版本说明

本次更新优化 AI 生成体验：AI 生成过程中可以离开生成页去使用其他功能，任务会在后台继续运行，完成后自动存入作品列表；「我的作品」页会置顶显示正在生成或失败的 AI 任务，可随时查看进度或取消任务；生成等待页恢复更直观的生成动画与进度提示；同时修复了返回首页后按钮仍显示“正在生成”的问题，并补充了生成失败的诊断日志。标准模式生成、作品编辑、保存与下载流程保持不变。

## 本次修改说明

1. **AI 任务后台化**：新增全局单例 `aiGenerationManager`（`miniprogram/services/ai-generation-manager.ts`），在 `App.onLaunch` 初始化并以 `allowBackground` 模式维持生成流程的轮询与结果获取；用户离开 AI 生成页后任务不再中断，完成后自动生成草稿作品并保存至本地作品集，同时提示“AI 拼豆图已生成完成”。与 AI 生成页并存时仍由页面承接结果并跳转编辑器，行为不变。
2. **增强「我的作品」页**：正在后台生成或已失败的 AI 任务置顶展示在作品列表中，状态标签区分“生成中”与“生成失败”，入口按钮按状态显示“查看进度 / 查看重试 / 继续编辑”，任务进行中或失败时仅提供“取消任务”操作，避免误触发重命名、分享等不可用动作；任务状态变化时列表自动刷新。
3. **修复首页状态残留**：首页 `onShow` 与 `startAiCreating` 的 `finally` 中严格重置 `generating` 状态，避免离开 AI 生成页后首页生成按钮一直提示“正在生成”而无法再次操作。
4. **移除误清理逻辑**：首页标准模式创建流程不再调用 `clearAiGenerationSession`，防止新建标准作品时误删除后台正在运行的 AI 任务。
5. **恢复生成中动画**：启用此前未被任何页面引用的 `generating-preview-card` 组件，AI 生成页在上传、提交、排队、处理、下载、转换阶段展示调色盘呼吸动画与按阶段推进的近似进度（12% → 28% → 45% → 68% → 86% → 94%）；底部提示胶囊优先展示网络重试、长时间等待等实时状态提示；加载态与失败态仍使用原状态卡片。同时为组件补充 `prefers-reduced-motion` 降级处理。
6. **新增 AI 输出格式诊断埋点（仅日志，不改变输出校验判定）**：`generateImage` 云函数记录落盘文件的 `headerContentType`、真实字节格式与签名；服务端 `HunyuanImageProvider` 在输出校验失败、云存储回下载失败时记录文件引用后缀、字节数、魔数签名与大小阈值，用于区分「非 PNG 格式」与「空内容」两类失败。
7. **统一版本与记录**：`package.json` 与 `package-lock.json` 版本升级为 `0.30.8`，补充 `docs/releases/CHANGELOG.md` 记录。

## 影响范围

- AI 生成的任务生命周期：启动、后台轮询、取消、结果落草稿
- 「我的作品」页列表数据组装、状态标签与卡片操作
- 首页生成按钮状态与标准模式创建流程
- AI 生成页生成中状态的视图与动画组件
- `generateImage` 云函数与服务端 `HunyuanImageProvider` 的失败日志字段
- 小程序版本号与 CHANGELOG

**不影响范围：**

- AI 生图云调用协议与成功返回字段（`fileID`、`contentType`、`size`、`revisedPrompt`、`requestId`）
- AI 输出校验判定逻辑（PNG 校验规则未改动，本次仅增加日志）
- 标准模式本地拼豆图生成算法
- 作品编辑、保存、作品列表和下载流程（除新增的 AI 任务卡片外）
- 登录、支付、额度扣减和既有后端 API 协议

## 提审验收重点

1. 首页进入 AI 生图流程后立即返回首页：首页按钮不再停留在“正在生成”，可正常再次发起生成。
2. 后台生成完成后，作品列表自动出现对应草稿作品，并收到“AI 拼豆图已生成完成”提示；打开后可正常编辑。
3. 「我的作品」页置顶展示生成中任务，标签与“查看进度”入口正确；点击进入后展示当前阶段进度与状态。
4. 生成失败的任务展示为失败态，支持“查看重试”与“取消任务”；取消后任务卡片从列表移除。
5. AI 生成页各阶段动画切换正常：上传 → 提交 → 排队 → 处理 → 下载 → 转换，进度条与提示文案随状态更新；弱网时可看到网络重试提示。
6. 在标准模式创建作品时，确认不会清除正在后台运行的 AI 任务。
7. 验证空提示词、网络失败、云函数失败、无效响应等场景下页面展示可理解的错误，且 AI 生成失败后仍可重试或切换标准模式。
8. 确认客户端包、接口响应和普通日志中不包含服务端 API Key 或模型返回的原始临时 URL。
