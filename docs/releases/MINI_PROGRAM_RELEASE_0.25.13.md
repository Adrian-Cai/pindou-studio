# 小程序 0.25.13 提交信息

## 版本号

`0.25.13`

## 用户可见更新说明

修复账号注销后无法再次使用同一微信登录的问题。再次登录会创建新的账号，不会恢复已注销账号的云端数据。

## 上传说明 / 项目备注

- 注销账号时会清除旧账号的微信登录标识与加密值，并撤销旧会话
- 同一微信再次登录时创建独立的新账号；旧账号的作品、下载记录、额度和订单不会被恢复或继承
- 普通“退出登录”流程不变，仍可直接重新登录原账号
- 服务端部署前需先执行 `server/sql/005_release_deleted_account_openid.sql`，再构建并重启服务

## 提审重点

1. 使用已登录测试账号进入“我的 → 隐私设置 → 注销账号”，确认二次确认后账号退出且云端账号数据不可访问
2. 返回“我的”页，使用相同微信再次登录，确认可成功进入新的空白账号并完成昵称设置
3. 检查新账号不展示旧账号的作品、下载记录、下载额度或订单数据
4. 使用未注销的账号执行“退出登录”后再次登录，确认原有账号数据仍正常可见
