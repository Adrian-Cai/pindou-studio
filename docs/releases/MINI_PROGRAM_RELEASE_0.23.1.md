# 小程序 0.23.1 提交信息

## 版本号

`0.23.1`

## 上传说明 / 项目备注

本次版本修复图片上传安全检测链路在本地开发环境下的兼容问题，并完善上传失败时的错误提示：

- **修复本地图片上传**：开发环境先执行同步图片安全检测，不依赖微信服务器访问本地 `127.0.0.1` 媒体地址；审核通过后正常显示图片预览并继续生成拼豆图。
- **保持生产审核链路**：体验版和正式版继续执行同步图片检测、`mediaCheckAsync` 异步审核及 callback 回调，不降低内容安全要求。
- **修复错误提示**：按错误类型区分图片格式不支持、图片无法解码、网络失败、登录异常、内容安全服务不可用和违规内容，避免后端错误被误提示为图片无法读取。
- **优化异常处理**：上传安全检测失败时可靠关闭 loading、恢复页面选择状态，并在开发环境输出不含凭据和用户隐私的排障日志。
- **兼容图片格式**：继续支持 JPG、PNG、WEBP；WEBP 仅转换安全审核副本，原图仍用于后续拼豆图生成。

## 提审备注

1. 图片上传仍会执行微信内容安全检测，违规图片会被拦截并提示“你发布的内容含违规信息，请修改后重试”。
2. 本地开发环境的同步审核不会影响体验版和正式版的完整异步审核流程。
3. 图片安全审核临时文件不作为作品资源长期保存；生产环境由异步 callback 或过期清理机制回收。
4. 本次不改变标准图案生成、编辑器、作品保存、下载、支付和 AI 精致模式的产品流程。

## 建议审核路径

1. 在微信开发者工具中选择普通 JPG、PNG 和 WEBP，确认显示“正在安全检测”。
2. 确认检测通过后能显示预览，并可以进入编辑器继续生成拼豆图。
3. 使用无法读取的图片，确认提示“图片无法读取，请换一张重试”。
4. 在后端不可用或网络失败时，确认提示网络/服务异常，而不是图片无法读取。
5. 在体验版环境上传正常图片，确认生产后端依次完成同步审核、`mediaCheckAsync` 和 callback。
6. 使用内容安全测试图片，确认违规图片被拦截且页面不会卡在 loading 状态。
