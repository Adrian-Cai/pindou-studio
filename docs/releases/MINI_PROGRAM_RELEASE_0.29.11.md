# 小程序 0.29.11 提审说明

## 版本号

`0.29.11`

## 建议提交信息

`fix: v0.29.11 优化 AI 生成加载布局`

## 微信小程序提审版本说明

优化「编辑拼豆图」页面的 AI 生成中体验：Loading 卡片改为独立紧凑布局，减少上下无意义留白；生成完成后再进入图片编辑区域，生成过程中不显示编辑信息和工具。

## 本次修改说明

1. **独立生成中布局**：AI Loading 卡片移出图片编辑画布容器，导航栏下方保持 12px 间距，卡片下方保持 16px 间距。
2. **避免固定高度占位**：生成过程中不挂载图片编辑画布的固定高度或 `min-height` 容器，页面只展示导航栏与 AI Loading 卡片。
3. **隔离编辑信息**：AI 生成完成前隐藏缩放、尺寸、颜色、颗数、工具栏、调色板和底部操作；生成完成后再切换到真实 ImageEditor 区域。
4. **保持视觉一致**：不修改 Loading 卡片现有紫色视觉风格、进度条和主要文案，也不改变 AI 生成流程和完成后的编辑能力。

## 影响范围

- 「编辑拼豆图」页面 AI 生成中状态的布局与状态渲染
- Loading 状态与图片编辑状态的切换体验
- 关于页版本展示与项目发布元数据

**不影响范围**：

- AI 任务创建、轮询、下载和图案转换流程
- 标准模式生成流程
- 生成完成后的画布、缩放、工具栏、调色板、保存和结果查看能力
- Loading 卡片内部紫色视觉、进度条和主要文案
