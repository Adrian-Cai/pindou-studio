# 小程序 0.32.0 提审说明

## 版本

- 小程序：`0.32.0`
- 服务端：`0.17.0`
- 建议提交信息：`release(releases): 准备小程序 0.32.0 提审`

## 微信审核版本说明

优化虚拟支付订单处理和账号登录安全。支付结果确认、重复操作和延迟到账的处理更加可靠，减少重复发放或付款后权益未到账的情况。退出登录时会立即清除本地登录凭证，并在网络可用时吊销当前服务端会话，降低旧凭证继续使用的风险。

## 本次更新

### 支付订单

- 同一购买意图重复提交时复用订单，限制未完成订单数量，并为每次微信支付尝试保留独立记录。
- 仅在核实微信支付事实后发放或扣回权益；推送验签、重复事件处理和定时补单共用幂等结算逻辑。
- 微信状态暂时无法确认时保留订单并等待后续核实，不把超时直接当作支付失败。

### 账号安全

- 增加当前会话和全设备会话吊销接口。
- 退出时先清除本地登录状态；异步恢复或刷新请求的迟到结果不能恢复已退出的登录态。
- 清除内容安全等服务使用的内存会话凭证。

## 发布前置条件

1. 部署服务端 `0.17.0`，确认健康检查返回正常。
2. 在生产数据库执行 `server/sql/018_payment_attempts_and_events.sql`。
3. 确认微信虚拟支付推送已配置 Token；使用安全模式时同时配置 EncodingAESKey。
4. 在微信开发者工具上传 `0.32.0`，先完成支付、取消后重试、延迟到账和退出登录的真实账号验收，再提交审核。
