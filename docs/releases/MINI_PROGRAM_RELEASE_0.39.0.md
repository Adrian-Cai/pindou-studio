- 小程序：`0.39.0`

## 微信审核版本说明

编辑图纸和查看 AI 生成结果时新增四边行列坐标，支持双指缩放及放大后平移；下载高清施工图时可按坐标对照拼装。另修复取消 AI 生成次数支付后再次购买可能提示订单已关闭的问题。

## 本次更新

- 普通编辑页、AI 生成成功页和高清施工图增加四边坐标标尺，坐标对应图纸网格，色号与拼豆颜色不变。
- 编辑器和 AI 生成结果支持双指缩放、放大后平移；按钮缩放范围扩展至 6 倍。
- 用户明确取消或微信关闭支付单后，下一次购买创建新订单；支付状态未知时保留原幂等键，避免重复下单。
- 关于页版本号更新至 `0.39.0`。
