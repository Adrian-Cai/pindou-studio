# 小程序 0.30.7 提审说明

## 版本号

`0.30.7`

## 建议提交信息

`fix: v0.30.7 修复云函数生图超时与入参解析`

## 微信小程序提审版本说明

修复 AI 生图云函数的稳定性问题：恢复生图请求的超时配置，避免因 SDK 默认超时导致生图请求被中断；固定云函数使用的云开发环境，避免生成结果写入错误环境；同时增强请求参数解析与失败诊断。标准模式、作品编辑、保存和下载流程保持不变。

## 本次修改说明

1. **修复生图请求超时**：`cloud.init` 恢复 `timeout: 900000`，云函数不再使用 `wx-server-sdk` 默认的 15 秒超时，避免耗时较长的混元生图调用被中断后统一返回“图片生成失败，请稍后重试”。
2. **固定云开发环境**：云开发环境固定为 `cloud.DYNAMIC_CURRENT_ENV`，不再读取可能被注入为其他环境的 `TCB_ENV`，避免 AI 调用和云存储写入落到错误环境，导致小程序无法读取已生成的图片。
3. **增强 HTTP 触发入参解析**：新增 `parsePayload`，支持 base64 编码请求体（`isBase64Encoded`）和已解析的对象请求体，数组或原始类型请求体按无效处理；解析失败时记录日志并返回独立的 `INVALID_BODY`，不再被误报为“请输入提示词”。
4. **增强失败诊断**：错误日志补充当前环境、上游状态码和厂商错误码；读取微信上下文失败时不再影响错误响应本身，非数值状态码不会被记录为 `NaN`。
5. **统一版本与配置**：小程序版本升级为 `0.30.7`，补充 CloudBase 部署配置 `cloudbaserc.json` 与云函数依赖锁定文件，云函数继续固定使用 `wx-server-sdk` `4.0.2`。
6. **完善忽略规则**：`.gitignore` 补充云函数 `node_modules`、本地环境变量 `.env*.local` 和编辑器工具目录。

## 影响范围

- `generateImage` 云函数的环境初始化、请求超时和入参解析
- 云函数失败日志与云函数调用返回的错误码
- 小程序版本号、CloudBase 部署配置与忽略规则

**不影响范围：**

- 小程序端 AI 生图入口、任务轮询和结果校验流程
- 云调用协议与成功返回字段（`fileID`、`contentType`、`size`、`revisedPrompt`、`requestId`）
- 标准模式本地拼豆图生成算法
- 作品编辑、保存、作品列表和下载流程
- 登录、支付、额度扣减和既有后端 API 协议

## 发布前置条件

1. 在微信云开发中确认当前小程序对应的云环境，并重新部署 `cloudfunctions/generateImage` 云函数及其依赖。
2. 确认云开发 AI 能力和混元图像模型权限已开通，云函数具备云存储写入权限。
3. 确认部署环境的 `TCB_ENV` 未被注入为其他云环境；云函数现已不再读取该变量。
4. 清除微信开发者工具缓存后重新编译，确认小程序版本显示为 `0.30.7`。
5. 使用真实测试账号完成一次生图联调后再提交审核；未配置生产 AI 能力时不应开放 AI 入口。

## 提审验收重点

1. 首页进入 AI 生图流程，分别验证默认、横屏、竖屏和方形尺寸均能成功返回图片。
2. 重点验证生图耗时超过 15 秒的场景：此前会被超时中断，现应正常返回图片。
3. 验证生成成功后云存储文件存在、临时访问地址可用，且结果可继续进入后续编辑流程。
4. 验证空提示词、超长提示词、网络失败、云函数失败、无效响应和临时地址读取失败时，页面展示可理解的错误。
5. 确认客户端包、接口响应和普通日志中不包含服务端 API Key 或模型返回的原始临时 URL。
6. 验证标准模式图片生成、编辑、保存、作品列表、下载和登录恢复流程未受影响。
