# 小程序 0.30.3 提审说明

## 版本号

`0.30.3`

## 建议提交信息

`feat: v0.30.3 接入云开发混元生图`

## 微信小程序提审版本说明

新增 AI 生图体验：通过微信云开发调用混元图像模型并将生成结果安全保存到云存储，支持多种图片尺寸和失败恢复提示；标准模式、作品编辑、保存和下载流程保持不变。

## 本次修改说明

1. **新增云函数生图入口**：新增 `generateImage` 云函数，校验提示词和图片尺寸，调用混元图像模型并下载模型返回的临时图片。
2. **安全保存生成结果**：云函数将生成图片写入云存储 `ai-images/` 目录，小程序只接收云存储 `fileID`，再按需换取临时访问地址。
3. **接入小程序云开发**：小程序启动时初始化云开发环境，新增生图服务封装网络错误、无效响应和云存储地址读取失败。
4. **统一版本配置**：小程序版本升级为 `0.30.3`，项目配置声明云函数目录，云函数固定使用 `wx-server-sdk` `4.0.2`。
5. **修正服务端模型配置**：服务端混元 TokenHub 配置统一使用官方模型 ID `HY-Image-v3.0-I2I-ToB-v1.0.1`，避免生产启动校验失败。

## 影响范围

- AI 生图入口、云开发初始化和云函数调用
- 混元生成结果的云存储持久化与临时地址读取
- 服务端混元模型配置校验和请求参数
- 小程序版本号与云函数目录配置

**不影响范围：**

- 标准模式本地拼豆图生成算法
- 作品编辑、保存、作品列表和下载流程
- 登录、支付、额度扣减和既有后端 API 协议

## 发布前置条件

1. 在微信云开发中配置当前小程序对应的云环境，并部署 `cloudfunctions/generateImage` 云函数及其依赖。
2. 确认云开发 AI 能力和混元图像模型权限已开通，云函数具备云存储写入权限。
3. 服务端配置 `HUNYUAN_IMAGE_API_KEY`、`HUNYUAN_IMAGE_BASE_URL=https://tokenhub.tencentmaas.com` 和 `HUNYUAN_IMAGE_MODEL=HY-Image-v3.0-I2I-ToB-v1.0.1`。
4. 清除微信开发者工具缓存后重新编译，确认小程序版本显示为 `0.30.3`。
5. 使用真实测试账号完成一次生图联调后再提交审核；未配置生产 AI 能力时不应开放 AI 入口。

## 提审验收重点

1. 首页进入 AI 生图流程，分别验证默认、横屏、竖屏和方形尺寸。
2. 验证生成成功后云存储文件存在、临时访问地址可用，且结果可继续进入后续编辑流程。
3. 验证空提示词、超长提示词、网络失败、云函数失败、无效响应和临时地址读取失败时，页面展示可理解的错误。
4. 确认客户端包、接口响应和普通日志中不包含服务端 API Key 或模型返回的原始临时 URL。
5. 验证标准模式图片生成、编辑、保存、作品列表、下载和登录恢复流程未受影响。
6. 确认服务端模型配置校验通过，已有混元 TokenHub 路径和数据库结构检查均正常。
