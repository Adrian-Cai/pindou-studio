# 小程序 0.38.3 提审说明

## 版本

- 小程序：`0.38.3`
- 服务端：保持 `0.22.7`；本次无服务端变更，无需重新部署。
- 数据库：无新增迁移。

## 提审背景

上一次提审因“AI 生成功能存在未授权公众人物人脸数据生成服务”被驳回，要求增加授权声明弹窗。0.38.2 的 AI 肖像使用提醒尚未提审，与本次封面优化一起作为 `0.38.3` 提交。

## 微信审核版本说明

AI 创作提交前新增肖像使用提醒弹窗：说明上传图片会提交给 AI 服务处理，上传含他人可识别肖像的图片前须告知本人并取得单独同意和必要授权，未经授权的公众人物肖像请勿上传，用户取消则不创建任务。同时优化“我的作品”图片展示：新保存的拼豆作品显示转换前原图，封面完整保留图片比例，原图不可恢复的旧作品继续显示现有封面。

## 本次更新

- AI 模式提交前展示肖像使用提醒弹窗；用户取消时不创建任务，确认后继续生成。
- 标准模式的新作品在本地保存、云端保存和断网补传后使用原图封面；编辑云端作品时保留已有原图封面。
- “我的作品”卡片完整显示原图，图片加载失败时继续显示现有占位图；打开、编辑和下载操作不变。
- AI 拼豆图和文生图作品继续使用已有原图封面；关于页版本号更新至 `0.38.3`。
