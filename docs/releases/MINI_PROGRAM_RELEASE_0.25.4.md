# 小程序 0.25.4 提交信息

## 版本号

`0.25.4`

## 上传说明 / 项目备注

本次版本为隐私入口与作品列表布局优化版本：

- 登录弹窗中的《隐私政策》改为可点击入口，跳转现有隐私政策文档页面。
- 优化“我的作品”卡片标题、状态标签和更多操作的布局，改善小屏显示和操作区域对齐。
- 微信开发者工具配置固定关闭 SWC 转译，保持当前 TypeScript 小程序构建链路稳定。
- 补充 Standard Pattern Engine V2 Phase 3 的微信 OffscreenCanvas 回归 fixture，用于真实 Canvas 结果持续校验。
- 不改变图片上传、图案生成、作品保存、下载和隐私设置的既有业务流程。

## 工程发布项

- Jenkins CNB 镜像拉取流水线支持 `Secret text` 类型的 `cnb-registry` 凭据；Token 仍由 Jenkins 凭据系统管理，不写入仓库。

## 提审备注

1. 打开“我的”页面，触发登录弹窗，点击《隐私政策》，确认能进入隐私政策页面。
2. 检查个人中心底部和“关于我们”页面，确认版本显示为 `0.25.4`。
3. 进入“我的作品”，确认作品标题、状态标签和更多操作在长标题及小屏设备上保持对齐。
4. 回归图片上传、标准图案生成、作品保存、编辑、下载和收藏流程。

## 提交前检查项

- 根目录 `npm run typecheck` 通过。
- 根目录 `npm run test:pattern` 通过。
- `git diff --check` 通过。
- 微信开发者工具完成重新编译，并在真机或预览环境完成隐私政策入口、作品列表和核心生成流程验收。
- 后端部署流水线使用已推送的 CNB 镜像完成健康检查。
