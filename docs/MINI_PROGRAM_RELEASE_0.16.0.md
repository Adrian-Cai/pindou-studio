# 小程序 0.16.0 提交信息

## 版本号

`0.16.0`

## 上传说明 / 项目备注

采用分包加载优化主包体积：将编辑器、作品结果、下载记录、我的收藏、使用帮助、关于我们、隐私设置、意见反馈、充值、支付成功 10 个二级页面整体移入 `pages-sub` 子包（`subPackages`），主包仅保留首页、我的作品、我的三个页面；首页示例图与品牌头像由 JPG/PNG 转为 WEBP 进一步缩减包体积，并同步更新首页、我的、我的作品页面对子包页面的跳转路径。

## 提审备注

1. **分包加载优化**：将 10 个二级业务页面（编辑器、作品结果、下载记录、我的收藏、使用帮助、关于我们、隐私设置、意见反馈、充值、支付成功）整体移入 `pages-sub` 分包，`app.json` 新增 `subPackages` 配置；主包只承载首页、我的作品、我的三个 Tab 页，显著降低主包体积与首次加载时间。
2. **图片资源瘦身**：首页 4 张示例图与品牌头像改用 WEBP 压缩格式，删除旧版 JPG/PNG 示例图与设计参考图，控制小程序包体上限。
3. **页面跳转与数据同步**：更新首页、我的、我的作品页面对子包页面的 `navigateTo` 路径（`pages/` → `pages-sub/`）及个人中心菜单配置数据，确保分包拆分后各功能入口与跳转不受影响。
4. **代码质量清理**：作品结果页拆分混合类型导入为独立 `import type` 语句，消除导包告警；不改变页面行为。

## 建议审核路径

1. 打开小程序首页，进入「我的」页面，通过菜单逐一进入「下载记录」「使用帮助」「意见反馈」「隐私设置」「关于我们」，验证子包页面均可正常打开、返回与导航正确。
2. 首页上传图片或点击示例图，进入「编辑」页（子包），完成生成后进入「作品结果」页（子包），验证完整生成本地流程与四个 Tab 的下载交互。
3. 进入「我的作品」打开作品详情、继续编辑、下载记录，验证跳转路径均为子包页面且行为正常。
4. 检查首页示例图与「我的」页品牌头像以 WEBP 格式正常显示，包体检查通过。
