# 小程序 0.15.0 提交信息

## 版本号

`0.15.0`

## 上传说明 / 项目备注

补齐作品结果页 4 个 Tab（成品图、材料清单、施工图、色板参考）统一下载半屏交互，包含下载确认半屏（DownloadConfirmSheet）与下载成功半屏（DownloadSuccessSheet）；优化下载额度扣除逻辑为仅在文件成功写入设备相册后扣减，增加防重复点击保护与大图预览支持。

## 提审备注

1. **统一下载半屏交互**：作品结果页的 4 个 Tab（成品图、材料清单、施工图、色板参考）点击下载按钮后，先弹出确认半屏，展示真实文件格式、保存位置、本次消耗（1次）及下载前剩余次数。
2. **下载成功状态**：保存成功后半屏切换至成功态，展示绿色发光成功图标、对应 Tab 保存提示、扣除后的真实剩余次数标签条（绿色高亮）、动态查看按钮（查看图片/查看施工图/查看色板）与完成按钮。
3. **安全与额度保障**：仅在文件成功保存至系统相册后扣减 1 次额度并生成记录；用户取消、权限拒绝或生成失败均不扣次，支持错误提示与重试；确认后禁用按钮防重复点击。
4. **大图预览支持**：下载成功后可直接点击主按钮调起原生大图预览，方便用户核对。

## 建议审核路径

1. 打开小程序首页，上传图片或点击示例图片，进入「作品结果」页。
2. 在「成品图」Tab 点击底部「下载成品图」按钮，调出下载确认半屏，验证标题、卡片说明及剩余次数。
3. 点击「确认下载」，授权相册保存权限，等待保存成功后自动切换至下载成功半屏。
4. 在成功半屏中点击「查看图片」验证原生图片全屏预览，返回后点击「完成」关闭半屏并留在当前页。
5. 依次切换到「材料清单」、「施工图」、「色板参考」Tab，验证各 Tab 专属的动态标题、文件说明与下载保存体验。
