# 小程序 0.7.0 提交信息

## 版本号

`0.7.0`

## 上传说明

接入微信登录与账号资料完善流程，新增云端账号状态恢复、退出登录、头像上传与昵称保存，并同步优化“我的”页默认头像和登录交互体验。

## 提审备注

- 本版本重点为微信登录、账号资料完善和个人中心体验升级。
- 审核时可在“我的”页点击顶部账号卡片，完成微信登录并体验登录态恢复、资料完善和退出流程。
- 当前已接入账号登录、用户资料读取、头像上传和基础权益展示。
- 微信支付、下载次数购买、作品云端保存与历史下载记录写入等后续服务仍未开放真实交易或完整线上闭环，相关入口仅展示当前阶段能力。

## 建议审核路径

1. 打开小程序后进入“我的”页，点击顶部账号卡片。
2. 完成微信登录，确认登录成功后自动进入资料完善弹层。
3. 选择头像、填写昵称并保存，返回“我的”页确认头像、昵称和账号状态已更新。
4. 再次打开账号面板，验证退出登录流程和游客态展示是否正常。
