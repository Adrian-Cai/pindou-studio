# 小程序 0.17.0 提交信息

## 版本号

`0.17.0`

## 上传说明 / 项目备注

升级标准模式图案采样：图片中心裁剪后先使用微信 Canvas 生成 4× 中间采样图，再按每颗豆对应的 4×4 区域进行 Linear RGB 平均，减少直接缩小造成的细节丢失和轮廓锯齿；透明边缘采用 Alpha 权重计算，避免隐藏 RGB 污染颜色。生成尺寸、颜色数量、编辑与保存流程保持不变。

## 提审备注

1. **标准模式采样升级**：标准模式由目标尺寸直接缩放升级为 4× Area Sampling，改善斜线、发丝、轮廓和渐变区域的稳定性。
2. **透明边缘处理**：区域颜色使用 Alpha 权重，透明像素不会污染可见颜色；透明判定继续使用原有 `alpha < 32` 规则。
3. **业务兼容保持**：`createDraft()`、图案数据结构、颜色数量、色号顺序、编辑器、作品保存与旧作品读取均保持现有接口和流程。
4. **验证情况**：纯算法测试 28 项全部通过；微信开发者工具真实 OffscreenCanvas 结构化 A/B 基线通过，并额外使用 7 张人物插画、线稿、渐变与宠物图片完成 64×64、32 色视觉对比。
5. **范围说明**：本版本未修改页面 UI、服务器、数据库或 Pattern Schema，也未加入 OKLab、MARD 色卡匹配、Cleanup、Edge Detection 或 AI 能力。

## 建议审核路径

1. 首页保持「标准模式」，分别上传人物插画、线稿或宠物照片，选择 64×64、32 色生成图案。
2. 检查人物五官、发丝、斜线轮廓、渐变区域和透明边缘，确认图案可以正常进入编辑器。
3. 在编辑器执行画笔、吸管、填充、橡皮擦、撤销和重做，确认工具行为不受采样升级影响。
4. 保存作品并从「我的作品」重新打开，确认尺寸、颜色、色号和 Cell 数据可以正常恢复。
5. 使用纯色或大面积平涂图片生成，确认颜色数量与透明 Cell 行为正常。
