# 一起拼豆吧 · 产品流程基线

> 状态：当前产品业务流程基线
>
> 适用版本：0.19.x
>
> 本文只定义用户流程、页面职责和关键业务约束。
> 技术架构见 `docs/architecture/CURRENT_ARCHITECTURE.md`，UI 规范见 `design.md` / `docs/frontend/UI_RULES.md`，接口见 `docs/backend/API_SPEC.md`，未来 AI 方案见 `docs/backend/AI_GENERATION_DESIGN.md`。

## 1. 产品定位

“一起拼豆吧”是一个把用户图片转换为可实际制作的拼豆方案的微信小程序。

核心目标不是单纯把图片像素化，而是完成以下闭环：

```text
选择图片
→ 生成拼豆草稿
→ 编辑调整
→ 保存作品
→ 查看结果
→ 查看成品图 / 材料清单 / 施工图 / 色板参考
→ 下载使用
```

## 2. 页面模型

### 2.1 一级 Tab

一级导航固定为三个入口：

| Tab | 页面 | 职责 |
| --- | --- | --- |
| 首页 | `pages/home/index` | 选择图片、生成模式和生成参数，开始新作品 |
| 作品 | `pages/projects/index` | 查看、筛选、打开、编辑、重命名和删除作品 |
| 我的 | `pages/profile/index` | 账号、统计、收藏、下载记录和设置入口 |

一级 Tab 之间使用 `switchTab`，不得把编辑器或结果页提升为一级 Tab。

### 2.2 二级页面

- `pages-sub/editor/index`：编辑拼豆草稿。
- `pages-sub/result/index`：查看作品结果并下载。
- `pages-sub/favorites/index`：收藏列表。
- `pages-sub/downloads/index`：下载记录。
- `pages-sub/recharge/index`：下载次数 / 额度相关展示。
- `pages-sub/payment-success/index`：支付成功展示页，当前支付闭环尚未正式接入。
- `pages-sub/help/index`：使用帮助。
- `pages-sub/feedback/index`：意见反馈。
- `pages-sub/privacy/index`：隐私设置。
- `pages-sub/about/index`：关于我们。

### 2.3 结果页不是四个独立页面

以下内容全部属于 `result` 页内部 Tab，不得再次拆成独立业务页面：

1. 成品图
2. 材料清单
3. 施工图
4. 色板参考

切换这四类内容只切换结果视图，不改变当前作品，也不产生新的页面级业务状态。

## 3. 新建作品主流程

### 3.1 标准模式

```text
首页
→ 选择“标准模式”
→ 选择图片
→ 设置尺寸 / 颜色数
→ 开始生成
→ 生成 PatternDraft
→ 编辑器
→ 用户调整图案
→ 保存并查看
→ 保存或更新作品
→ 结果页
```

关键规则：

- 标准模式生成成功后先进入编辑器，不直接进入结果页。
- 编辑器中的修改必须持续写回当前 `PatternDraft`。
- 点击“保存并查看”时，必须先完成作品持久化，再进入结果页。
- 游客保存到本地；已登录用户保存或更新云端作品。
- 编辑已有作品时，应更新原作品，不创建无意义的重复作品。

### 3.2 AI 精致模式

AI 精致模式当前只保留产品入口和说明，真实 AI 生成链路尚未上线。

当前行为：

```text
选择 AI 精致模式
→ 点击开始生成
→ 明确提示“即将上线”
→ 不执行标准模式作为伪 AI 结果
```

在真实 AI 能力接入前，不得在产品流程、文案或数据中把 AI 生成描述成已完成能力。

## 4. 已有作品流程

```text
作品 Tab
→ 搜索 / 筛选作品
→ 选择作品
├─ 查看 → 读取作品数据 → 结果页
├─ 编辑 → 读取作品数据 → 编辑器 → 保存并查看 → 结果页
├─ 重命名 → 更新作品名称
└─ 删除 → 二次确认 → 删除作品
```

规则：

- 云端作品在进入编辑器或结果页前，先拉取完整作品数据并恢复为当前草稿。
- 本地作品只有具备可恢复的网格数据时才能继续编辑或查看结果；缺失数据时应明确提示，不伪造结果。
- 删除属于破坏性操作，必须二次确认。
- 新建作品统一回到首页，不从作品页复制一套生成流程。

## 5. 结果与下载流程

结果页围绕“同一作品的四种输出”工作：

```text
结果页
→ 选择结果 Tab
→ 点击下载
→ 检查剩余下载次数
→ 确认下载
→ 生成文件
→ 成功保存到设备相册
→ 记录下载
→ 扣减一次额度
→ 展示成功状态
```

不可破坏的下载规则：

- 成品图、材料清单、施工图、色板参考分别按一次成功下载计次。
- 只有文件真实保存到设备成功后，才能记录下载并扣减额度。
- 用户取消、生成失败、权限拒绝或保存失败时不得扣减次数。
- 云端下载记录使用幂等键，避免重复扣减。
- 额度不足时引导到额度 / 会员入口，不得继续伪装下载成功。

当前购买 / 微信支付完整闭环尚未正式接入，因此相关页面只能表达真实可用状态，不能展示虚假的支付成功结果。

## 6. 收藏流程

```text
结果页收藏 / 取消收藏
→ 更新当前作品收藏状态
→ 收藏列表同步变化
→ “我的”收藏数量同步变化
```

收藏属于作品的同一业务状态，必须满足：

- 收藏按钮状态、收藏列表和“我的”收藏数量使用同一事实来源。
- 收藏或取消收藏完成后，各入口再次展示时必须一致。
- 不允许一个页面使用本地状态、另一个页面使用未同步的云端统计后对用户展示冲突数字。

当前收藏云端同步仍属于待完善能力；在完成统一数据源之前，不应把云端收藏闭环描述为已完成。

## 7. 登录与作品同步

```text
游客使用
→ 作品保存在本地
→ 用户微信登录
→ 建立云端会话
→ 刷新账号数据
→ 迁移可迁移的本地作品
→ 后续优先使用云端作品
```

规则：

- 登录不能导致本地作品丢失。
- 本地作品迁移成功后，相关作品 ID 应同步更新到依赖该作品的本地关联数据。
- 迁移失败时保留本地作品，并允许后续重试。
- 退出登录后停止访问云端作品和云端下载记录，但不得删除本机草稿。

## 8. “我的”入口流程

“我的”页负责聚合账号与辅助功能，不承担作品生成逻辑。

主要入口：

```text
我的
├─ 作品数量 → 作品 Tab
├─ 收藏数量 → 收藏列表
├─ 下载数量 → 下载记录
├─ 账号区域 → 登录 / 账号 / 资料编辑
├─ 下载次数 / 套餐 → 额度相关入口
├─ 使用帮助
├─ 意见反馈
├─ 隐私设置
└─ 关于我们
```

支付能力未正式接入前，套餐入口只能展示或提示未开放状态，不得形成假的支付闭环。

## 9. 核心状态一致性规则

以下状态必须跨页面一致：

| 状态 | 必须一致的入口 |
| --- | --- |
| 当前作品 | 编辑器、结果页、作品列表 |
| 作品名称 | 作品列表、结果页 |
| 收藏状态 / 数量 | 结果页、收藏列表、我的 |
| 下载次数 | 结果页、我的、额度入口 |
| 下载记录 | 下载成功状态、下载记录、我的统计 |
| 登录状态 | 我的、作品云端读取、下载额度 |

原则：同一个业务事实只能有一个权威来源；本地缓存可以作为离线或临时展示，但不得长期与权威状态并行漂移。

## 10. 文档边界与维护规则

本文不重复以下内容：

- 图像算法、Canvas、Pattern Engine 实现细节。
- PostgreSQL、后端模块或文件存储结构。
- API 请求 / 响应字段。
- UI 颜色、间距、组件尺寸和视觉规范。
- 尚未落地的未来 AI 技术方案。

以下变化发生时必须同步更新本文：

- 一级 Tab 或二级页面职责发生变化。
- 新建作品、编辑、保存、结果、下载主链路发生变化。
- 收藏、作品、下载、登录的数据权威来源发生变化。
- AI 精致模式或支付能力正式上线并改变用户流程。

如果本文与当前可运行代码不一致，先确认是“文档落后”还是“代码偏离产品设计”；不得为了迁就旧文档直接修改核心业务流程。
