# 小程序 0.19.0 提交信息

## 版本号

`0.19.0`

## 上传说明 / 项目备注

优化登录后的作品数据衔接：登录或恢复登录时自动将本地作品迁移到云端，保留作品标题、收藏状态和下载记录；同步失败或本地数据不完整时继续保留原记录，不影响离线使用。接入阶段 4 云端额度与下载记录，并修复图片保存成功后“我的”页面下载次数和剩余额度未及时刷新的问题。

## 提审备注

1. **本地作品迁移**：游客状态创建并保存的本地作品，会在用户登录或恢复有效登录态后逐份同步到当前用户的云端作品列表。
2. **数据安全与重试**：每份本地作品持久化完整图案草稿；同步使用稳定幂等键，失败、弱网或数据不完整时保留本地作品，不删除用户数据，可在后续登录时重试。
3. **关联状态保留**：迁移成功后用云端作品替换对应本地作品，并同步更新当前草稿、收藏关联和历史下载记录中的作品 ID。
4. **服务端下载闭环**：登录用户在图片真实保存成功后，使用幂等键调用 `POST /api/downloads`；个人页、结果页和下载记录页分别读取服务端额度或下载记录，服务端失败时保留本地缓存兜底。
5. **个人页状态刷新**：下载成功后同步更新登录资料缓存中的下载总数、今日已用次数和剩余额度，返回“我的”页面即可看到最新数值。
6. **范围说明**：本版本不改变图片生成、编辑、作品保存和下载到相册的交互流程；服务端当前阶段 4 契约不包含 `palette`，色板参考继续使用本地下载记录。

## 建议审核路径

1. 未登录时从首页生成一份作品，在编辑页保存后进入“我的作品”，确认作品保存在本地且可以重新打开。
2. 进入“我的”并完成微信登录，等待同步结束后进入“我的作品”，确认原本地作品已变为云端作品，标题、封面和图案内容保持一致。
3. 在弱网或后端不可用时重复上述登录流程，确认同步失败不会删除本地作品；网络恢复后重新登录可继续同步，且不会创建重复作品。
4. 对迁移前的本地作品执行收藏或产生下载记录，登录迁移后确认收藏状态和下载历史仍关联到迁移后的云端作品。
5. 在作品结果页成功保存一张图片，返回“我的”页面，确认下载次数增加且剩余额度立即刷新；取消、拒绝相册权限或保存失败时不应扣减。
