# CODE_RULES.md


# 代码质量规范


## 复用原则


优先级：

1. 已有代码。
2. 已有依赖。
3. 平台能力。
4. 新增代码。


---

# 依赖管理


禁止：

无需求新增依赖。


---

# TypeScript


要求：

- 类型明确。
- 避免any。
- 保持类型安全。


---

# 数据管理


禁止：

业务数据写入页面。


推荐：

data/

config/

services/


---

# 文件大小


限制：

页面：

300行以内。


组件：

500行以内。


最大：

800行。


超过：

必须拆分。


---

# 简洁原则


优先：

简单实现。


禁止：

过度封装。
