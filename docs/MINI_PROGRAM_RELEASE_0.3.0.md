# 小程序 0.3.0 提交信息

## 版本号

`0.3.0`

## 上传说明

完善作品管理和个人中心，新增收藏、下载记录、帮助、反馈、隐私及关于页面，统一导航、安全区与交互体验。

## 提审备注

- 本版本主要完善作品管理、个人中心及相关辅助页面。
- 作品、收藏、下载记录和隐私偏好使用本地存储，可直接体验页面流程。
- 微信支付、云同步、文件导出、历史作品详情和反馈提交服务暂未接入；相关入口会明确提示，不会产生真实交易或伪造成功状态。

## 建议审核路径

1. 首页选择示例图片，设置尺寸和颜色数量后进入编辑页。
2. 保存作品并查看作品结果。
3. 通过底部导航进入“作品”，体验搜索、筛选、收藏和删除确认。
4. 进入“我的”，查看收藏、下载记录、使用帮助、意见反馈、隐私设置和关于我们。
