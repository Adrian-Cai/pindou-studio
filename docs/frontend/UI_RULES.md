# UI_RULES.md

# UI设计原则

本项目采用：

设计稿驱动开发。

优先级：

Figma/UI稿 > AI默认设计

---

# 开发前设计分析

实现页面前：

必须分析设计稿。

包括：

## 页面结构

分析：

- 页面层级
- 模块顺序
- 信息优先级

## 视觉规范

提取：

- 页面padding
- 模块间距
- 卡片尺寸
- 圆角
- 字体大小
- 字重
- 颜色
- 阴影

## 组件拆分

确定：

- 页面组件
- 公共组件
- 状态组件

---

# UI还原规则

必须：

- 保持布局结构一致。
- 保持模块顺序一致。
- 保持视觉层级一致。

禁止：

- 自行增加模块。
- 自行删除模块。
- 修改交互方式。
- 使用默认组件替代设计。

例如：

设计稿：

按钮

禁止：

改成滑块。

设计稿：

卡片选择

禁止：

改成下拉选择。

---

# 组件规范

优先复用：

- Button
- Card
- Upload
- Modal
- BottomSheet
- Tab

禁止：

重复创建相同组件。

---

# UI验收流程

完成页面后：

必须：

1. 启动项目。
2. 截图。
3. 对比设计稿。

检查：

- 布局
- 尺寸
- 间距
- 字体
- 颜色
- 圆角

发现差异：

优先修复视觉问题。

# 自定义导航栏与页面滚动规范

## 1. 页面基础结构

凡使用自定义导航栏的页面，统一采用：

```text
PageLayout
├── CustomNavbar
└── ScrollArea
```

要求：

- 状态栏安全区固定
- 自定义导航栏固定
- 页面正文独立滚动
- 正文不得带着导航栏一起滚动
- 不允许将导航栏放入正文 scroll-view 内

---

## 2. 固定范围

默认只固定：

- 状态栏安全区
- 页面导航栏
- 返回按钮
- 页面标题
- 微信胶囊对应操作区域

业务内容默认不得固定，包括：

- 作品信息卡
- 用户信息卡
- 图片预览
- 功能卡片
- 统计卡片

除非 UI 设计明确要求。

---

## 3. ScrollView

长页面优先采用：

固定 Header + 独立 scroll-view

不要依赖整个 page 自然滚动再通过 fixed / sticky 临时修复。

正文滚动区域必须正确避开导航栏高度。

不得出现：

- 内容被导航栏遮挡
- 导航栏跟随正文消失
- 双重滚动
- 页面滚动穿透

---

## 4. Tab 吸顶

存在 Tab 的详情页，例如：

- 成品图
- 材料清单
- 施工图
- 色板参考

默认行为：

1. 导航栏始终固定
2. 作品信息区随页面正常滚动
3. Tab 滚动到导航栏下方后允许吸顶
4. Tab 吸顶后不得遮挡导航栏
5. 切换 Tab 时保持正确滚动状态

禁止直接把“导航栏 + 作品信息 + Tab”全部固定。

---

## 5. 禁止硬编码顶部高度

禁止使用类似：

```css
padding-top: 44px;
margin-top: 88rpx;
top: 64px;
```
