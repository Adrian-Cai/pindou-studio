# UI_RULES.md

# UI设计原则

本项目采用：

设计稿驱动开发。

优先级：

Figma/UI稿 > AI默认设计

---

# 排版与韵律（Typography）

## 字体

- 标题和按钮仅使用 `Inter Tight`。
- 回退字体使用 `Inter, system-ui`。

## 文字层级

- H1：`22/28px`，Semibold，字间距 `-0.7px`。
- H2/章节：`19/24px`，Semibold，字间距 `+0.6px`。
- 正文/日期：`14.5/18px`，Regular，字间距 `+0.3px`。

## 色彩语义

- `--text`：主要文本，对比度必须达到 `≥ 7:1`。
- `--muted`：辅助文本，对比度必须达到 `≥ 4.5:1`；严禁使用纯灰色，建议带有色相倾向。
- `--strong`：图标和强调元素。

---

# 组件与空间（Components）

## 按钮（Ghost/Glass）

- 尺寸直径：`38–46px`；触控目标必须满足 `44px` 标准。
- 样式不使用实色填充，依赖 `6px` 内嵌高光和柔和投影。
- Hover/Active 态叠加 `--strong` `5%` 透明度填充，确保弱光环境下仍可见。

## 卡片（Cards）

- 圆角：小卡片 `12px`，大容器 `18px`。
- 禁止使用 `border`，改用多层 `box-shadow`，例如：

```css
box-shadow: 0px 4px 12px rgba(0, 0, 0, 0.05),
  0px 1px 2px rgba(0, 0, 0, 0.1);
```

---

# 布局与分割（Layout）

## 间距系统

基于 `4px` 网格，允许使用的间距为：

`4, 8, 12, 16, 24, 32, 48, 64px`

## 分隔线

- 仅在需要进行内容区隔时使用分隔线。
- 分隔线使用 `1px` 实色 `var(--track)`。
- 卡片内元素间距达到 `16px` 或以上时，不使用分割线，依赖间距留白完成区隔。

---

# 动态响应（Interaction）

## 点击反馈

所有交互元素必须提供点击反馈：

- 使用 `transform: scale(0.97)`，或使用透明度变化。
- 过渡持续时间统一为 `150ms`。

## 暗黑模式

- 深色模式下，`--text` 与 `--muted` 必须反转亮度，保持文字层级和可读性。
- 深色模式下阴影使用更低的不透明度，并保持更暗的阴影表现。

# UI还原规则

必须：

- 保持布局结构一致。
- 保持模块顺序一致。
- 保持视觉层级一致。

禁止：

- 自行增加模块。
- 自行删除模块。
- 修改交互方式。
- 使用默认组件替代设计。

例如：

设计稿：

按钮

禁止：

改成滑块。

设计稿：

卡片选择

禁止：

改成下拉选择。

---

# 组件规范

优先复用：

- Button
- Card
- Upload
- Modal
- BottomSheet
- Tab

禁止：

重复创建相同组件。

- 布局

- 间距

# 自定义导航栏与页面滚动规范

## 1. 页面基础结构

凡使用自定义导航栏的页面，统一采用：

```text
PageLayout
├── CustomNavbar
└── ScrollArea
```

要求：

- 状态栏安全区固定
- 自定义导航栏固定
- 页面正文独立滚动
- 正文不得带着导航栏一起滚动
- 不允许将导航栏放入正文 scroll-view 内

---

## 2. 固定范围

默认只固定：

- 状态栏安全区
- 页面导航栏
- 返回按钮
- 页面标题
- 微信胶囊对应操作区域

业务内容默认不得固定，包括：

- 作品信息卡
- 用户信息卡
- 图片预览
- 功能卡片
- 统计卡片

除非 UI 设计明确要求。

---

## 3. ScrollView

长页面优先采用：

固定 Header + 独立 scroll-view

不要依赖整个 page 自然滚动再通过 fixed / sticky 临时修复。

正文滚动区域必须正确避开导航栏高度。

不得出现：

- 内容被导航栏遮挡
- 导航栏跟随正文消失
- 双重滚动
- 页面滚动穿透

---

## 4. Tab 吸顶

存在 Tab 的详情页，例如：

- 成品图
- 材料清单
- 施工图
- 色板参考

默认行为：

1. 导航栏始终固定
2. 作品信息区随页面正常滚动
3. Tab 滚动到导航栏下方后允许吸顶
4. Tab 吸顶后不得遮挡导航栏
5. 切换 Tab 时保持正确滚动状态

禁止直接把“导航栏 + 作品信息 + Tab”全部固定。

---

## 5. 禁止硬编码顶部高度

禁止使用类似：

```css
padding-top: 44px;
margin-top: 88rpx;
top: 64px;
```
