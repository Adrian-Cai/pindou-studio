# 拼豆精选作品页设计草案

## 页面目标

展示经过挑选的优质拼豆作品，作为浏览灵感和话题推荐链接的落点。它与现有“作品”页区分：现有页管理用户自己的创作，这一页面向公开浏览。

第一阶段按精选作品集设计，先展示作品图、名称、作者和制作规格；投稿、点赞、评论等社区功能等内容和运营方式明确后再规划。

## 设计规格

- 视觉方向：温暖的手作杂志感，作品图是页面主体，留白承接页面信息。
- 色彩：品牌绿 `#12B466`、米白底 `#FFFDF7`、浅薄荷 `#ECF8F0`、深墨正文 `#17211C`；后续实现优先映射到项目现有颜色变量。
- 字体：标题沿用 `Inter Tight`，正文沿用项目现有字体规则。
- 页面框架：复用统一 `PageLayout`、固定 `CustomNavbar` 和独立滚动区，遵守安全区与底部 Tab 避让规范。
- 图片：主推作品使用 4:3 大图；图集作品优先展示完整成品，不遮挡作品关键细节。

## 页面结构

```text
┌──────────────────────────┐
│ 状态栏 / 微信胶囊          │ 固定
│ 拼豆灵感                  │ 自定义导航栏
├──────────────────────────┤
│ 精选拼豆作品              │ 页面说明
│ 发现值得收藏的拼豆灵感     │
│                          │
│ ┌──────────────────────┐ │
│ │ 本周精选作品图 4:3    │ │ 主推作品
│ └──────────────────────┘ │
│ 作品名 · 作者 · 尺寸/色数  │
│                          │
│ 精选作品                 │
│ [全部] [图纸] [新手] [礼物]│ 轻量分类入口
│                          │
│ ┌──────────┐ ┌──────────┐│
│ │ 作品图   │ │ 作品图   ││
│ │ 作品名   │ │ 作品名   ││ 两列图集
│ │ 作者规格 │ │ 作者规格 ││
│ └──────────┘ └──────────┘│
│       ……                 │ 独立滚动内容
├──────────────────────────┤
│ 首页       作品       我的 │ 沿用现有底部导航
└──────────────────────────┘
```

作品卡片建议只显示精选标识、作品名、作者和尺寸/色数。精选作品图在后台人工挑选；此草案中的图集代表真实作品素材位，不使用话题背景图冒充用户作品。

## 入口与路径

- 首页增加“拼豆灵感”入口，进入精选作品页；保留现有“作品”Tab 作为个人创作管理区。
- 候选页面路径：`pages/inspiration/index`。
- 当前小程序尚未注册或实现该路径，不能填入贴图话题的推荐链接。待页面实现并加入路由后，再用实际页面路径更新话题记录。
- 当前可用的 `pages/create/index?source=image` 仍只负责开始创作，不作为精选作品页路径。
