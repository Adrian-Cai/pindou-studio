# UI_RULES.md


# UI设计原则


本项目采用：

设计稿驱动开发。


优先级：

Figma/UI稿 > AI默认设计


---

# 开发前设计分析


实现页面前：

必须分析设计稿。


包括：


## 页面结构

分析：

- 页面层级
- 模块顺序
- 信息优先级


## 视觉规范


提取：

- 页面padding
- 模块间距
- 卡片尺寸
- 圆角
- 字体大小
- 字重
- 颜色
- 阴影


## 组件拆分


确定：

- 页面组件
- 公共组件
- 状态组件


---

# UI还原规则


必须：

- 保持布局结构一致。
- 保持模块顺序一致。
- 保持视觉层级一致。


禁止：

- 自行增加模块。
- 自行删除模块。
- 修改交互方式。
- 使用默认组件替代设计。


例如：

设计稿：

按钮


禁止：

改成滑块。


设计稿：

卡片选择


禁止：

改成下拉选择。


---

# 组件规范


优先复用：

- Button
- Card
- Upload
- Modal
- BottomSheet
- Tab


禁止：

重复创建相同组件。


---

# UI验收流程


完成页面后：

必须：

1. 启动项目。
2. 截图。
3. 对比设计稿。


检查：

- 布局
- 尺寸
- 间距
- 字体
- 颜色
- 圆角


发现差异：

优先修复视觉问题。
